# Тачки — бот оценки машин на перепродажу

Присылаете боту в Telegram Excel со списком машин от продавца. В ответ приходит Excel с тремя листами:
**«Берём»** (ликвидные, с хорошей маржой, отсортированы по прибыли), **«Отсеяно»** (с причиной и этапом) и **«Условия»**.

## Как считается

| Этап | Что делает | Стоимость |
|---|---|---|
| **Цена** | `цена × 0,85` (скидка продавца); для полного НДС ещё `× 0,86` — цена за наличку | — |
| **1. Файл** | Отсев: старше 8 лет, пробег > 150 000 км, > 30 000 км/год, чёрный список марок | бесплатно |
| **2. Рынок** | Claude ищет похожие объявления на Авито, Авто.ру, Дроме, отзывы и форумы (drive2 и др.): медиана цены, число объявлений, ликвидность 1–10, срок продажи, болячки. Отсев: ликвидность < 6, прибыль < 150 000 ₽ | ~несколько ₽ за машину (API Claude) |
| **3. Автотека** | Только для прошедших рынок. Отсев: 3+ владельца, 2+ ДТП, скрутка, реальный пробег больше заявленного, залог/розыск/такси | платный отчёт |

`прибыль = медиана рынка × 0,95 (торг) − цена за наличку − 40 000 ₽ (подготовка)`

Все пороги меняются в `.env` (см. `.env.example`), текущие показывает команда `/settings`.

## Формат файла

Бот сам ищет строку с заголовками (над таблицей может быть шапка). Понимает колонки:
**Марка** + **Модель** (или одна «Наименование»/«Марка, модель»), **Год**, **Пробег**, **Цена/Стоимость**, **VIN**, **НДС** (необязательно).
Пустые и итоговые строки без цены пропускаются. Остальные колонки (комплектация, двигатель…) передаются в анализ рынка.

## Запуск

Нужен Python 3.10+ и компьютер/сервер с доступом в интернет (VPS за ~300 ₽/мес подойдёт).

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # заполнить токены
python -m carbot
```

Проверка логики без сети: `pytest -q`.

### Что где взять
- **TELEGRAM_BOT_TOKEN** — @BotFather → `/newbot`.
- **ANTHROPIC_API_KEY** — console.anthropic.com → API Keys (оплата картой, списывается за использование).
- **ALLOWED_USER_IDS** — напишите боту `/start`, он ответит вашим id.
- **Автотека** — бизнес-доступ через Avito API (autoteka.ru → «Для бизнеса»), нужны `client_id` и `client_secret`. Пока их нет, бот доходит до этапа 2, а перспективные машины помечает «пробить VIN вручную».
  Сырые отчёты сохраняются в `reports/`. Пути API вынесены в начало `carbot/autoteka.py`: если в вашем договоре они другие, поправьте там.

## Структура

```
carbot/
  bot.py        Telegram: приём файла, прогресс, отправка результата
  pipeline.py   этапы 1→2→3
  pricing.py    −15 %, ×0,86, прибыль
  filters.py    этап 1
  market.py     этап 2: Claude + веб-поиск
  autoteka.py   этап 3: API Автотеки, поиск скрутки
  excel_io.py   чтение «грязного» Excel и сборка отчёта
  config.py     пороги из .env
site-draft/     черновик сайта автосалона (на паузе)
```
