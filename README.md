# Тачки — отбор машин на перепродажу

Берёт Excel-реестр изъятых машин и возвращает Excel с ликвидными машинами и прибылью по каждой.
**Работает бесплатно:** цены бот сам собирает с Дрома, Авто.ру и Авито. Запускается у вас на компьютере: через Telegram-бота или перетаскиванием файла на значок.

## Как считается

**Цена закупки:** `стартовая цена (СРС с переоценкой) − 15 %`, затем `× 0,86` (наличка, полный НДС). В отчёте видны все три шага.
**Рынок:** у каждой площадки своя медиана похожих объявлений; итог — медиана трёх площадок.
**Прибыль:** `рынок × 0,95 (торг) − цена закупки − 40 000 ₽ (подготовка)`.
**Вывод о выгоде делается только когда проверены все три площадки.** Если какая-то не открылась (капча, бан), машина остаётся в «Кандидатах» с пометкой, что не проверено.

| Этап | Что делает | Цена |
|---|---|---|
| **1. Файл** | Оставляет только легковые со статусом «В продаже». Отсев: правый руль; «Нет ключей»; состояние HARD и «Удовлетворительное»; в комментариях тотал, «после ДТП», «не на ходу», сгорел и т. п.; выпуск раньше 2018; пробег > 100 000 км или > 30 000 км/год. пробег 0–1 км или пустой (машину не смогли запустить) | бесплатно |
| **2. Рынок** | **Дром** — обычными запросами; **Авто.ру** и **Авито** — в настоящем браузере Chrome (эти площадки не пускают программы). По каждой: «б/у, тот же год» по всей России, объявления с похожим пробегом (±35 %), без битых, без крайних 10 % цен → медиана. На Авито из выдачи берётся только та же модель (Tiggo 7 Pro ≠ Tiggo 7 Pro Max) и год. Ликвидность — по числу объявлений: 300+ → 9/10, 40+ → 6/10, меньше 10 → 3/10; для машин дороже 8 и 15 млн — ниже. Отсев: ликвидность < 6, прибыль < 400 000 ₽ | бесплатно |
| **3. Автотека** | Только для прошедших рынок: 3+ владельца, 2+ ДТП, скрутка, залог — мимо. Без доступа к API этап пропускается, VIN пробиваете вручную | платно, по желанию |

Все пороги — в файле `.env` (образец — `.env.example`).

## Что в отчёте

| Лист | Что там |
|---|---|
| **Сводка** | Главное: итоги плитками, топ-10 по прибыли, воронка, причины отсева, условия |
| **Берём** | Прошли всё. Цена по шагам (СРС → −15 % → × 0,86), медиана Дрома, Авто.ру и Авито, итог рынка, прибыль, маржа, ликвидность, ссылки на все три площадки, фото, код лота |
| **Прибыль по всем** | Все машины, оценённые на рынке, — и «БЕРЁМ», и «нет» с причиной. Видно, что не дотянуло до порога |
| **Кандидаты** | Прошли бесплатный отсев, но рынок не проверялся (режим «только список» или Дром ограничил доступ) |
| **Отсеяно (легковые)** | Каждая отсеянная легковая машина и причина. Грузовики, прицепы, спецтехника в отчёт не попадают |

## Установка на Windows

1. Установите **Python 3.11+** с python.org. В установщике поставьте галочку **«Add python.exe to PATH»**.
2. Скачайте проект: на GitHub кнопка **Code → Download ZIP**, распакуйте, например, в `C:\Тачки`.
3. **Проверить файл без Telegram:** перетащите Excel на `проверить_файл.bat`. При первом запуске он сам поставит всё нужное, включая браузер (2–5 минут). Во время проверки откроется окно браузера с Авто.ру и Авито — не закрывайте его; если площадка спросит «я не робот», решите капчу, бот подождёт и продолжит. Отчёт `Оценка_<имя>.xlsx` появится рядом с исходным файлом.
4. **Telegram-бот:** напишите @BotFather → `/newbot`, скопируйте токен в `.env` (строка `TELEGRAM_BOT_TOKEN=`), запустите `запустить_бота.bat`, напишите боту `/start`. Он ответит вашим id — впишите его в `ALLOWED_USER_IDS=` и перезапустите, чтобы ботом не пользовались чужие. Бот работает, пока открыто чёрное окно и включён компьютер.

Linux / macOS / сервер:
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && cp .env.example .env
python -m carbot.cli реестр.xlsx      # разово по файлу
python -m carbot                      # Telegram-бот
```

## Если что-то пошло не так

- **Капча на Авто.ру или Авито.** Решите её в окне браузера — бот ждёт до 3 минут (`CAPTCHA_WAIT_SEC`). Если не успели, площадка до конца проверки пропускается, а машины без неё остаются в «Кандидатах». Запустите файл ещё раз позже.
- **«Дром ограничил доступ».** Подождите час и запустите снова; можно увеличить паузы `DROM_DELAY_MIN/MAX` и `BROWSER_DELAY_MIN/MAX` в `.env`.
- **«Не нашёл модель … на Дроме».** Бот сопоставляет названия из реестра с каталогом Дрома автоматически; редкие случаи можно поправить в `drom_slugs.json`.
- **Цены не разобрались.** Страница сохраняется в папку `debug/` (`drom_…`, `autoru_…`, `avito_…`). Пришлите эти файлы — парсер поправим.
- **Не запустился браузер.** В папке проекта выполните `.venv\Scripts\python -m playwright install chromium`.

## Платный режим (по желанию)

`MARKET_SOURCE=claude` — вместо Дрома рынок анализирует Claude с веб-поиском: Авито, Авто.ру, Дром, форумы, типичные болячки. Нужен `ANTHROPIC_API_KEY`, примерно $0,3–0,5 за модель.

## Структура

```
carbot/
  bot.py        Telegram: файл → сводка бесплатного отсева → кнопка → отчёт
  cli.py        то же без Telegram
  pipeline.py   этапы 1 → 2 → 3
  multimarket.py рынок по трём площадкам и итоговый вывод
  drom.py       Дром (обычные запросы)
  autoru.py     Авто.ру (браузер)
  avito.py      Авито (браузер)
  browser.py    окно Chrome, ожидание капчи
  listings.py   общий разбор объявлений, похожие по пробегу, медиана
  report.py     оформление отчёта
  market.py     платный рынок: Claude + веб-поиск
  autoteka.py   история по VIN
  filters.py    этап 1
  pricing.py    −15 %, × 0,86, прибыль
  excel_io.py   чтение реестра
  config.py     пороги из .env
site-draft/     черновик сайта автосалона (на паузе)
```
